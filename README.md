# 📝 Daily To-Do List

A clean, modern, and fully functional **Daily Task Tracker** website that helps you organize your daily activities, stay productive, and never miss a task. Your tasks are automatically saved in your browser's local storage, so you never lose your progress — even after closing the browser.

🔗 **Live Demo:** [https://rakesh6430.github.io/simple_task_tracker_website/](#) *(Replace with your live link)*

---

## ✨ Features

| Feature | Description |
| :--- | :--- |
| ✅ **Add Tasks** | Quickly add new tasks with a single click or by pressing Enter |
| ✅ **Mark Complete** | Check off tasks as you complete them |
| ✅ **Delete Tasks** | Remove tasks you no longer need |
| ✅ **Filter Tasks** | View All, Active (pending), or Completed tasks |
| ✅ **Task Timestamps** | Each task shows when it was created |
| ✅ **Task Statistics** | Real-time counter showing completed vs. total tasks |
| ✅ **Auto-Save** | Tasks are automatically saved in your browser's LocalStorage |
| ✅ **Responsive Design** | Works perfectly on desktop, tablet, and mobile devices |
| ✅ **Custom Tab Icon** | Beautiful purple checkmark favicon in your browser tab |
| ✅ **Animated UI** | Smooth fade-in animations and hover effects |
